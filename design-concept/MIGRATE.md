# SubManager — дизайн-концепт → перенос в React-проект

## Что в архиве

| Файл | Экран | Что внутри |
|---|---|---|
| `index.html` | Дашборд | hero с тогглом Месяц/Год, интерактивный график (crosshair + прогноз), прогресс месяца, таймлайн списаний, donut по категориям, сетка подписок, оверлей деталей подписки, шторка добавления |
| `analytics.html` | Аналитика | bar-chart по месяцам (кликабельные бары), статистика, категории, топ по цене, инсайт-карточка |
| `friends.html` | Друзья | сводка по split-возвратам, «Ждут перевода» / «Оплатили», демо напоминаний |
| `profile.html` | Профиль | аккаунт, привязка Telegram, настройки, экспорт, выход |
| `auth.html` | Авторизация | Google + email, переключение вход/регистрация, заметка про TMA |

Все страницы связаны между собой ссылками через таббар. JS — чистый vanilla, без зависимостей, всю логику можно читать прямо в `<script>` внизу каждого файла.

## Дизайн-токены (скопировать в проект как есть)

```css
:root{
  --bg:#0b0b10; --surface:#14141d; --surface2:#1c1c28;
  --border:rgba(255,255,255,.07);
  --accent:#a78bfa; --accent-deep:#7c5cf0;
  --text:#f4f4f7; --dim:#8f8fa0;
  --up:#ef8f8f; --dn:#8fe3b0;
}
```

Шрифты: **Bebas Neue** (заголовки, uppercase) + **Manrope** 400–800 (всё остальное).
Мобильный фрейм: `max-width:390px`. Анимация появления: `rise .6s cubic-bezier(.2,.7,.3,1)` со стаггером через `animation-delay`.

## Порядок переноса

1. **Токены + шрифты** → `index.css` / файл темы (если Tailwind — в `theme.extend.colors`).
2. **Экраны по одному**, в том порядке, в каком делали: Dashboard → Analytics → Friends → Profile → Auth. Не всё сразу.
3. **Повторно используемое вынести в компоненты**: `TabBar` (с центральной FAB), `Card`, `Toggle` (.sw), `Logo` (буква/SVG из `ICONS` в index.html), `SegmentedControl`.
4. **Мок-данные** (объекты `SUBS`, `PRESETS`, массивы месяцев) → `src/mocks/` — потом заменятся на IndexedDB/API.
5. **Интерактив переносить состоянием React**: график — точки + pointer events, donut — stroke-dasharray, шторка и детали — conditional render + те же CSS-переходы.

```

токенам, отступам и анимациям оттуда.

Шаг 1: перенеси дизайн-токены (:root из любого файла) и шрифты Bebas Neue +
Manrope в тему проекта. Шаг 2: спортируй index.html в компонент Dashboard на
React, разбив на подкомпоненты (Hero, SpendChart, Donut, Timeline, SubsGrid).
Интерактив (тоггл месяц/год, crosshair на графике, donut-легенда) сохрани.
Мок-данные вынеси в src/mocks. Остальные экраны портируем следующими шагами —
не трогай их, пока не попрошу.
```
